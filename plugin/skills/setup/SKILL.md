# 처음 설정

먼저 `read_settings` 를 `{}` 로 불러 지금 설정을 읽는다. 이미 말한 것이 있으면 다시 묻지 않고, 한 번에 하나씩 묻는다.

1. 「새 쪽지를 조직 전체에 보일까요, 나만 볼까요?」 답을 `defaultVisibility` 에 `조직 전체` 나 `나만` 으로 넣는다.
2. 「보관한 쪽지도 목록에 보일까요?」 답을 `showArchived` 에 넣는다.

지금 설정을 그대로 두거나 건너뛰겠다고 하면 고치지 않는다. 바꾸겠다는 칸만 `set` 에 담아 `update_settings` 를 부른다.
예를 들어 나만 보고 보관한 것은 숨기면 `{"set":{"defaultVisibility":"나만","showArchived":false}}` 다.
저장됐는지는 도구가 돌려준 값으로 확인하고, 도구가 실패했으면 저장됐다고 말하지 않는다.

끝나면 `open_library` 를 `{}` 로 불러 쪽지 목록을 연다. 다른 일을 하던 대화에서 깔았다면 그 일을 이어서 한다.
