# 출시 전 점검표

`chatgpt-plugin-launch` 스킬의 2단계(출시 전)와 3단계(제출)를 이 저장소에 대어 본 표다. 2026-10-18 브랜치
`claude/hathway-plugin-ux-6yhjlc` 기준이고, 줄마다 표시 하나와 한 줄 설명을 단다.

| 표시 | 뜻 |
|---|---|
| ✓ | 이 브랜치에서 끝냈다 |
| ○ | 코드나 문서로 할 일이 남았다 |
| 👤 | 사람만 할 수 있다(구매 · 콘솔 · 비밀값 · 결정) |

## 2-1. 배포와 도메인

- 👤 **도메인을 산다.** `vercel.app` 은 Google OAuth 브랜딩이 홈페이지를 거절한다. 구매에는 사용자 승인과 등록자 정보가 필요하다.
- 👤 Vercel 프로젝트를 만들고 도메인을 붙인다(www 는 apex 로 308). production 에만 실물 환경변수를 넣고, `WEB_DATABASE_URL` 은 풀러(6543)다.
- ○ 도메인이 정해지면 한 PR 에서 옮긴다: `NEXT_PUBLIC_SITE_URL`, Supabase `site_url` · 허용 주소(`supabase/config.toml` 은 로컬 값뿐이다), 플러그인 매니페스트, MCP 주소. canonical · sitemap · llms.txt 는 이미 `NEXT_PUBLIC_SITE_URL` 에서 만들어져 따라온다.
- ○ `apps/web/vercel.json` 에 없는 라우트(`/api/toss/renew`)를 부르는 cron 이 남아 있다. 결제 모듈을 켜지 않았으니 지운다.
- ○ 머지 뒤 production 배포가 CANCELED 로 끝나지 않았는지 본다.

## 2-2. 개인정보처리방침 · 이용약관

- ✓ `/privacy` 를 코드의 실제 흐름에서 다시 썼다. Google 로그인, AI 앱 연결(Supabase OAuth), 조직과 팀, 공개되는 리서치 보드, 쪽지, 플러그인 설정, 쪽지 요약(AI Gateway → Anthropic), PostHog(고르기 전에는 보내지 않고 거절하면 쿠키 없이), 공시에 실린 이름이 들어갔다.
- ✓ `/terms` 에 「투자 자문이 아니에요」와 「시장 자료의 출처와 정확성」 조를 더했다. 투자 권유를 하지 않고, 계산은 이용자의 가정으로 낸 연습의 결과이며, DART 가 정본이고 자료가 늦거나 틀릴 수 있다고 적었다.
- ✓ 운영 주체(팍스휴마나 · 대표 연주환 · 사업자등록번호 · 주소 · 통신판매업 신고번호 · contact@paxhumana.io)를 `content/legal/index.ts` 의 `LEGAL` 한 곳에 넣었다. 보호책임자는 대표다.
- ✓ Google 사용자 데이터 절(Limited Use)을 한국어와 영어로 두었다.
- ✓ 바닥글에 처리방침이 굵게 서 있다(`SiteFooter.tsx`).
- 👤 **대표 전화를 적을지 정한다.** 저장소가 공개라서 `LEGAL.phone` 을 자리표시(`[대표 전화]`)로 두었고, 지금은 화면에 대괄호가 선다.
- 👤 Supabase 원격 프로젝트의 리전이 서울(ap-northeast-2)인지 대시보드에서 확인한다. 다르면 `LEGAL.region` 과 처리방침 8절을 고친다.
- 👤 PostHog 세션 리플레이를 켤지 정한다. 켜면 처리방침 1 · 5 · 8절에 「화면 이용 녹화」(동의한 사람만 · 입력 가림 · 30일)를 더한다.
- ✓ 연결 동의 화면(`/oauth/consent`)의 「연결하기」 아래에 로그인 화면과 같은 약관 안내(`LegalNote`)를 두었다.
- ○ 시행일을 2026-10-25 로 두었다. 배포 날짜가 정해지면 7일 앞서 알리도록 다시 맞춘다.
- ○ 쪽지와 쪽지 요약은 예시 도메인이다. 걷어 내면 처리방침과 약관에서 그 항목과 Anthropic 위탁을 함께 뺀다.

## 2-4. PostHog

- ✓ 코드는 갖춰져 있다. `/ingest` 프록시, `cookieless_mode: "on_reject"`, 동의 쿠키가 정본이다(`modules/posthog/client.ts`).
- 👤 US 리전 프로젝트를 만들고 `phc_` 토큰을 Vercel production 에만 넣는다. 프리뷰는 `NEXT_PUBLIC_POSTHOG_SINK=rehearsal` 이다. 결제 한도는 $0 으로 둔다.
- 👤 PostHog 프로젝트 설정에서 「Cookieless server hash mode」를 켠다. 꺼 두면 거절한 사람의 방문 수가 세어지지 않는다.
- ○ 배포 뒤 동의와 거절 두 길을 실물에서 본다(데스크톱 UA, `--disable-blink-features=AutomationControlled`).

## 2-5. SEO · GEO · Search Console

- ✓ 뿌리 레이아웃은 noindex 이고, `(site)` · `(market)` 레이아웃이 색인을 연다.
- ✓ `robots.txt` 는 API · 인증 · `/ingest` 를 막고 공개 화면을 연다.
- ✓ `sitemap.xml` 은 시장 화면(주식 · 종목 분석 · 거시경제 · 산업 지도와 산업마다의 밸류체인 · 뉴스 · 리서치 보드), 문서, 블로그, 새 소식, 약관을 싣는다. 다른 주소로 넘기는 `/` 는 뺐다.
- ✓ `llms.txt` 에 제품 설명, 「투자 자문이 아니에요」 고지, 공개 화면, MCP 엔드포인트(`/api/mcp`)와 연결 문서를 실었다.
- ✓ `(site)` 레이아웃에 JSON-LD(`Organization` · `WebApplication`)를 실었다.
- ✓ `app/opengraph-image.tsx` 를 더하고 `/opengraph-image` 를 미들웨어의 `PUBLIC_PATHS` 에 넣었다. 한글이 네모로 찍히지 않도록 Pretendard 부분 글꼴을 싣는다.
- ✓ 문서 「ChatGPT에서 쓰기」(`/docs/chatgpt`)를 더하고 「시작하기」를 제품의 일로 다시 썼다.
- ○ 종목 화면(`/stocks/analysis/<종목 코드>`)은 sitemap 에 없다. 상장사 2천여 곳을 실으려면 `generateSitemaps` 로 DB 를 읽어야 한다.
- ✓ 내용이 없는 부동산 화면 넷(첫 화면 · 종목 분석 · 거시경제 · 뉴스)에 noindex 를 달았고 sitemap 에서도 뺐다.
- ✓ 블로그는 제품 소개 한 편(`/blog/hello`)으로, 새 소식 0.1.0 은 새 바탕으로 옮긴 일과 ChatGPT 앱 첫판으로 바꿨다. 스캐폴드의 쪽지 글은 걷었다.
- ○ 시장 화면에 JSON-LD 가 없다. 블로그 밖의 공개 화면이라 `(market)` 레이아웃에도 같은 값을 싣는다.
- 👤 Search Console 에 Domain 속성(TXT)과 HTML 파일 확인을 하고, 서비스 계정을 사용자로 더하고, sitemap 을 낸다. 확인 파일은 지우지 않는다.

## 2-6. 영어 화면

- ○ 처리방침과 약관의 영어판(`privacy.en.mdx` · `terms.en.mdx`)이 없다. Google 사용자 데이터 절만 영어가 있다.

## 3. 제출

- ○ 리뷰 계정: 전용 `/review-login`, `REVIEW_ACCOUNT_EMAILS` 허용 목록, 멱등 시드가 아직 없다.
- 👤 리뷰 계정의 비밀번호를 정한다. 만든 스레드 밖으로 옮기지 않는다.
- ○ 테스트 케이스: 성공 5개와 실패 3개를 「말한 것 → 불릴 도구 → 보일 것」으로 쓴다. 흐름표(`흐름표.md`)의 도구 지도가 재료다.
- ○ 데모 영상을 실물 ChatGPT 에서 찍는다(설치 · 연결 · 종목 요약 → 적정가 계산 → 보드에 담기).
- ○ 이름 · 10KB 미만 로고 · 상표 고지 · 처리방침과 약관 주소를 맞춘다. 약관에 「ChatGPT 는 OpenAI 의 상표」 고지는 이미 있다.
- 👤 제출 양식의 Review details 에 리뷰 계정과 순서를 적는다.
- 👤 제출 뒤 OpenAI 앱 id 를 받아 홈의 「ChatGPT에서 열기」와 딥링크를 맞춘다.
