# hathway 기업분석 플러그인 · 흐름표와 도구 지도

2026-10-18 · SSO-82 · 이 파일이 정본이다.
방법은 scaffold `chatgpt-plugin-launch/references/ux-methodology.md` 를 따른다.
비슷한 서비스의 컴포넌트 조사는 같은 폴더의 `조사-비슷한-서비스.md` 에 있다.

## 0. 한 줄로

**대화가 분석이고, 화면은 숫자를 한눈에 보여 주는 곳이다.** 모델이 플러그인 스킬(company-analysis · industry-analysis ·
industry-map)로 생각하고, 도구는 DART 원자료(`fin_periods` · 공시 · 지분)에서 **출처가 붙은 숫자**만 낸다. 화면은 그 숫자를
표 · 막대 · 사다리로 세우고, 단추는 다시 대화로 돌아간다.

⚠ 이 제품은 교재 방법론의 **분석 연습**이다. 투자 자문이 아니다. 숫자가 나오는 모든 카드의 바닥에 출처와 「분석 연습용 자료예요.
투자 판단은 스스로 하세요.」 한 줄을 둔다.

## 1. 핵심 루프

```
종목 이름을 말한다 → 요약 카드(숫자 셋 + 5년 추이) → 「분석 시작」
  → 모델이 해자 · 산업 · 매출 추정을 말로 쌓는다 (재무 · 피어 · 공시 카드를 필요할 때 부른다)
  → 적정가 카드(3년 뒤 순이익 × PER = 적정가, ÷3 = 매수가, 9칸 시나리오)
  → 「리서치 보드에 담기」 → 다음에 사이드바에서 다시 연다
```

갈래는 「처음 · 찾기 · 한 종목 파기 · 비교와 산업 · 값 매기기 · 기록」 여섯이다.

## 2. 도구 지도

| 도구 | 누가 | 화면 | 자리 | 하는 일 |
|---|---|---|---|---|
| `find_company` | 모델 | 없음 | 글 | 이름 · 코드로 종목을 찾는다. 여럿이면 모델이 고른다 |
| `show_company` | 모델 | `ui://hathway/company/v1` | 인라인 카드 → 크게 보기 | 종목 요약: 업종 · 시장, TTM 매출 · 영업이익률 · ROE · 부채비율, 5년 매출 · 영업이익 막대 |
| `show_financials` | 모델 | `ui://hathway/financials/v1` | 인라인 카드 | 연간 · 분기 · TTM 추이 표와 막대. 고른 계정 셋까지 |
| `compare_peers` | 모델 | `ui://hathway/peers/v1` | 인라인 카드(표) | 피어 넷~여섯의 매출 성장 · 영업이익률 · ROE 비교, 이 종목 줄을 굵게 |
| `value_company` | 모델 | `ui://hathway/valuation/v1` | 인라인 카드 → 크게 보기 | 적정가 계산. 입력(3년 뒤 매출 · 순이익률 · PER 세 시나리오)을 모델이 넣고 서버가 순수 규칙으로 계산한다 |
| `list_filings` | 모델 | `ui://hathway/filings/v1` | 인라인 카드 | 최근 공시 · 주요사항 · 지분 변동 타임라인. 원문은 DART 링크(우리 것이 아닌 곳이라 밖으로 나가도 된다) |
| `screen_stocks` | 모델 | `ui://hathway/screen/v1` | 크게 보기 | 업종 접두 · 성장률 · 이익률 조건의 후보 표 |
| `open_home` | 사람(사이드바) | `ui://hathway/home/v1` | 사이드바 | 내 리서치 보드, 최근 본 종목, 산업 지도 묶음, 「분석 시작」 빠른 행동 |
| `open_boards` | 사람(패널) | `ui://hathway/boards/v1` | 스레드 패널 | 리서치 보드 서랍. 고르면 「대화에 추가」 |
| `save_to_board` | 모델 · 화면 | 없음 | 글 | 지금 분석의 요약 · 숫자를 보드 위젯으로 담는다 |
| `browse_company` | 화면만 (`visibility: ["app"]`) | — | — | 크게 보기 · 사이드바 안에서 계정 · 기간을 바꿀 때 데이터를 받는다 |
| `search_mentions` | 호스트 | — | 멘션 | `@` 로 종목 · 보드를 찾는다(데스크톱) |

주 단추 원칙: 인라인 카드의 주 단추는 다음 한 걸음을 **보내기**(`ui/message`)이고, 보조는 **대화에 추가**(`ui/update-model-context`)
또는 **크게 보기**다. 사이드바의 주 단추는 「분석 시작」(보내기), 패널의 주 단추는 「대화에 추가」다.

## 4. 클라이언트

- 웹 · 데스크톱: 카드 · 크게 보기 · 사이드바 · 패널. 멘션은 데스크톱만.
- 음성: 화면이 뜨지 않는 것으로 보인다. 모든 도구의 `content` 가 숫자 셋과 출처를 말로 담는다.
- 모바일: 크게 보기 표는 가로로 밀지 않고 열을 줄인다(종목 · 핵심 숫자 둘).

## 5. 정할 것(아침에)

1. 플러그인 이름. 기본값은 「Hathway 기업분석」으로 두었다.
2. 주가 · 시가총액. DB 에 없다. 적정가 카드의 「오늘 주가 대비」 칸은 모델이 웹에서 받은 값을 입력으로 넣고 출처를 적는다(기본값).
3. 리서치 보드를 플러그인에서 쓰려면 로그인이 필요하다. 읽기는 공개(웹과 같다), 담기는 로그인 뒤.
