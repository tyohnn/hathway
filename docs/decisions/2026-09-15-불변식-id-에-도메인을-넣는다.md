# 불변식 id 에 도메인을 넣는다 (2026-09-15)

> agent-campus 로 옮기며 남긴 기록입니다(2026-09-28). 본문의 resolv · advisor 는 옮기기 전의 이름입니다.

`docs/decisions/2026-09-14-약어-규약.md` 의 불변식 id 형식을 갈음한다. 나머지 조항은 그대로다.

## 정한 것

```
INV-<도메인>-<두 자리>      INV-LEGAL-01 · INV-AGENT-01
REQ-<두 자리>               REQ-01
```

**도메인 불변식은 그 도메인 패키지가 갖는다.** `packages/legal/src/invariants.ts` 에 legal 것
서른, `packages/agents/src/invariants.ts` 에 agent 것이 온다.

**`REQ-*` 에 도메인 구간이 없는 것이 곧 신호다.** 코드가 아니라 만드는 방식에 거는 규약이라
어느 도메인에도 딸리지 않고, 그래서 `packages/shared/src/invariants/requirements.ts` 에 있다.

종류(앱·데이터)는 id 에 넣지 않는다. 카탈로그의 `kind` 칸이 이미 말하고 있어서 id 가 또 말하면
사본이 된다.

## 고려한 것

종전 id 는 `INV-A01`(앱) · `INV-D01`(데이터)였다. 도메인이 없어서 카탈로그를 나누는 순간
`packages/agents` 의 `INV-A01` 과 충돌한다.

| 안 | 모양 | 버린 까닭 |
|---|---|---|
| 글자를 도메인에 배정 | legal 은 `A`·`D`, agents 는 다른 글자 | 기존 인용을 안 고쳐도 되지만 그 글자가 무슨 뜻인지 외워야 한다. `A`·`D` 가 이미 그 문제였다 |
| 종류를 단어로 | `INV-LEGAL-APP-01` | id 가 길어지는데 그 구간이 말하는 것을 `kind` 칸이 이미 말한다 |
| **종류를 빼고 도메인을 넣는다** | `INV-LEGAL-01` | 고른 것 |

## 고른 까닭

1. **도메인 규칙은 그 도메인이 소유한다.** 「배정자는 정확히 한 명」이 `packages/agents` 에게는
   아무 뜻이 없다. 같은 파일에 둘 이유가 없고, `packages/legal` 이 열람권 판정을 단독 소유하는
   것과 같은 원칙이다.
2. **찾을 수 있어야 쓴다.** `packages/agents` 는 테스트 여든 개가 도는데 불변식이 하나도 없었다.
   카탈로그가 `packages/legal` 아래 있어서 agent 쪽 작업자가 그 파일을 만날 일이 없었던 것이
   가장 그럴듯한 설명이다.
3. **글자는 뜻을 말하지 않는다.** 종류를 `A`·`D` 로 적던 것이 그 증거다. 도메인을 `L`·`G` 로
   줄이면 같은 자리로 돌아간다.

## 놓아준 것

- 인용 530 곳을 치환했다. 순수 비용이고, 지금이 가장 쌌다. 도메인이 늘면 더 는다.
- 서른 개를 한 줄로 다시 매겼다. `INV-A01`~`A22` 가 `INV-LEGAL-01`~`22` 로, `INV-D01`~`D08` 이
  `INV-LEGAL-23`~`30` 으로 간다. 옛 id 를 아는 사람은 이 표를 봐야 한다.
- `packages/agents` 가 `@campus/shared` 를 의존하게 됐다. 카탈로그들이 같은 `Invariant` 타입을
  쓰려면 그 타입이 어느 도메인에도 딸리지 않은 자리에 있어야 한다. D-2026-09-14-30 이 막는
  것은 `legal ↔ agents` 라 어기지 않는다.

## 코드에서 지키는 자리

- `packages/shared/src/invariants/types.ts` — 카탈로그들이 함께 쓰는 타입
- `packages/shared/src/invariants/requirements.ts` — 도메인이 없는 `REQ-*` 여섯
- `packages/shared/scripts/check-invariants.mjs` — 카탈로그 셋을 함께 읽는다. **카탈로그가 남의
  도메인 id 를 선언하면 실패한다.** 도메인 없는 옛 id(`INV-A01`)를 쓰는 것도 막는다.
- 검사는 `@campus/shared` 의 `test` 에 물려 있어 `turbo test` 와 CI 가 함께 돌린다.
