# 플러그인 익스텐션은 MCP 위의 표시이고 SDK 없이 얹는다

OpenAI 가 낸 플러그인 익스텐션(<https://developers.openai.com/plugins/build/extensions>)을 스캐폴드에 세우면서 정한 것이다.
스펙은 <https://github.com/openai/mcp-extensions/blob/main/docs/spec.md> 이고 2026-10-02 의 판을 읽었다.

## 정한 것

- **익스텐션은 모듈 `plugin` 으로 선다.** `./create.sh --with plugin` 으로 고르고, 고르지 않으면 코어의 도구 둘만 도는 MCP 가 남는다.
  스펙의 익스텐션 열둘을 모두 세운다(사용자 결정). 본보기는 예시 도메인 `notes` 다.
- **코어에 확장 지점 `McpSurface` 를 하나 더한다.** 모듈이 MCP 에 더하는 도구 · 자원 · capability 를 답한다. 기본 구현은 아무것도
  더하지 않는다. MCP 요청의 조립은 라우트에서 `usecases/mcp.ts` 로 내린다.
- **서버도 화면도 SDK 를 쓰지 않는다.** `lib/mcp.ts` 의 순수 함수에 익스텐션의 표시를 손으로 얹고, 화면(iframe)은
  `postMessage` 위의 JSON-RPC 를 직접 쓴다.
- **`/api/mcp` 가 두 시대를 함께 받는다.** `initialize` 로 악수하는 옛 판과, 요청마다 판과 capability 를 싣고 오는
  새 판(2026-07-28)이다.
- **리치 폼은 새 판의 왕복으로만 낸다.** 되물을 때 맡기는 상태(`requestState`)는 서명해서 내고 대조해서 받는다.
- **설정은 표에 저장한다**(사용자 결정). 새 도메인 패키지 `packages/preferences` 와 스키마 `preferences` 가 선다.
- **화면은 HTML 한 장으로 구워 커밋한다.** `app/build.mjs` 가 esbuild 로 굽고, 테스트가 구운 것과 소스가 같은지 잰다.
- **도구의 이름에 점을 쓰지 않는다.** `open_library` 처럼 밑줄로 잇는다.

## 까닭

- 익스텐션은 따로 서는 패키지가 아니라 MCP 서버 위의 표시다. 도구의 `_meta` 와 capability 가 전부이고 스펙이 그 모양을
  평범한 JSON 으로 적어 두었다. 이 저장소의 MCP 는 SDK 없이 순수 함수 하나로 서 있고 그 덕에 도커 없이 재는데, 서버 SDK
  (`@openai/mcp-extensions/server`)는 `@modelcontextprotocol/sdk` 의 `McpServer` 를 요구해서 그 봉투를 통째로 갈아야 한다.
- 화면 쪽 SDK 는 `@modelcontextprotocol/ext-apps ^1.7.5` 를 요구하는데 그 패키지는 이미 2.x 다. SDK 스스로도 「자기 화면을
  가진 앱을 위한 최소 전송」을 100줄 남짓으로 싣고 있어서, 화면과 호스트 사이의 말이 그만큼이라는 것을 보여 준다.
- 코어가 익스텐션을 알면 ChatGPT 전용 표시가 코어에 섞인다. 확장 지점 하나로 받으면 모듈을 떼는 일이 「가진 자리를
  지우고 잇는 줄을 걷는다」로 남는다. 요금제의 문(`PlanLimits.mcp`)은 코어의 조립이 한 번 걸어서 모듈의 도구도 같은 문을 지난다.
- OpenAI 가 등록한 서버에 요구하는 폼의 길이 새 판의 왕복이다. 옛 판의 되묻기는 서버가 열린 연결로 요청을 내야 하는데,
  이 라우트는 요청 사이에 아무것도 기억하지 않는다. 왕복은 그 성질과 맞는다. 서버가 「폼이 필요하다」로 답하고 클라이언트가
  답을 실어 같은 호출을 다시 보낸다.
- 상태를 서명하지 않으면 폼을 받은 적 없는 요청이 답만 지어 보내 도구의 뒷부분을 곧바로 돌린다. 누구에게 어느 도구로
  언제까지 낸 것인지를 함께 서명한다. 폼의 답 자체도 믿지 않고 유스케이스로 다시 연다.
- 설정을 메모리에 두면 서버리스 인스턴스마다 흩어져서, 방금 바꾼 값이 다음에 열면 사라진다. 스캐폴드로 만든 제품을 바로
  배포해 쓰려면 표가 있어야 한다. 줄의 열쇠가 멤버십을 가리키고, 포트가 행위자만 받아 남의 설정을 가리킬 길이 없다.
- 굽는 일을 빌드에 걸면 모듈을 뗄 때 `package.json` 의 스크립트가 없는 파일을 가리킨다. 구운 것을 커밋하면 배포에 굽는
  단계가 없고, 낡은 것은 테스트가 잡는다.
- 스펙의 본보기는 `cad.library` 처럼 점을 쓴다. 이 서버에는 클로드 코드도 붙고 그쪽은 도구 이름에 영문자 · 숫자 · 밑줄 ·
  붙임표만 받는다.

## 확인하지 못한 것

로컬에서 잴 수 없어서 남긴 것이다. 실물 ChatGPT 에 붙여 본 사람이 확인하고, 틀렸으면 이 파일을 고치지 않고 새 결정을 더한다.

- **왕복 안에서 쓰는 폼의 메서드 이름.** 스펙은 옛 판의 예만 싣고 「`elicitation/create` 를 `openai/elicitation/create` 로
  바꾸라」고 적는다. 그 말을 따랐다. 바꿀 자리는 `apps/web/src/modules/plugin/forms.ts` 의 `FORM_METHOD` 하나다.
- **Supabase 의 OAuth 서버가 `resource` 를 토큰의 `aud` 에 싣는가.** ChatGPT 는 인가와 토큰 요청에 `resource` 를 붙인다.
  우리 서버는 토큰을 `getUser(token)` 으로 확인하고 `aud` 를 보지 않는다. 로컬의 인증 서버는 동적 등록 · S256 ·
  `none` 을 알리고 CIMD 는 알리지 않는다.
- **호스트가 익스텐션의 표시를 그대로 받는가.** e2e 는 호스트를 흉내 낸 창으로 우리 쪽의 말만 잰다.
