# 결정

왜 그렇게 정했는지를 남기는 자리다. 한 결정에 한 파일이고, **적은 뒤에는 고치지 않는다.**
판단이 바뀌면 새 파일을 더하고 앞의 것을 가리킨다.

- 파일 이름은 `YYYY-MM-DD-무엇을-정했나.md` 다.
- 본문은 정한 것과 그 이유를 적는다. 되돌리면 안 되는 이유와 실측 근거가 있으면 함께 적는다.
- 한국어 산문은 `.claude/skills/fluent-korean/` 지침을 따른다.

⚠ **2026-09-29 이전의 파일은 물려받은 기록이다.** resolv-ai 에서 세운 결정 가운데 이 스캐폴드에도 그대로
통하는 것만 옮겼다. 본문의 `advisor` · `legal` · 자문 같은 이름은 그 결정이 처음 선 자리를 가리키고,
이 저장소에서는 앱 이름과 도메인 이름을 바꿔 읽는다(`advisor_app` → 앱마다의 롤, 열람권 → 행 단위 판정).
고치지 않는 까닭은 위와 같다.

도메인마다 있는 불변식 카탈로그와 그 인용 검사가 「지금 무엇이 지켜지는가」를 답하고, 이 폴더는
「왜 그렇게 정했나」만 답한다.

무엇이 있는지는 이 폴더가 아니라 라우트 디렉터리와 테스트 이름이 답한다.
