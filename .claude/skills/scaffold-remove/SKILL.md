# 모듈을 뗀다

`/scaffold-add` 의 거꾸로다. 원본에서 「모듈 있음」과 「모듈 없음」을 새로 찍고, 그 차이를 프로젝트에 옮긴다.

모듈이 가진 파일은 지우고, 코어에 잇는 줄은 걷는다. 프로젝트가 갈라진 자리는 네가 `wiring.md` 의 「뗄 때의 차례」대로 판단한다.

## 차례

### 1. 준비

- `scaffold.json` 을 읽는다. 없으면 `/scaffold-add` 의 1번대로 값을 찾는다.
- **원본의** `<source>/modules/<모듈>/wiring.md` 를 읽는다. 프로젝트의 `modules/<모듈>/` 은 떼면 함께 사라진다.
- 다른 모듈이 이 모듈을 `requires` 하면 스크립트가 멈춘다. 그 모듈부터 뗄지 사람에게 묻는다.
- `scaffold.json` 의 `adopted` 에 있는 모듈은 `/scaffold-fit` 이 제품 코드로 편입한 것이다. 스크립트가 멈추고, 그 코드는 제품의 코드로 직접 고친다.
- **무엇이 사라지는지 사람에게 한 문단으로 말한다.** 다음 셋이 들어가야 한다.
  - 화면
  - 메뉴
  - 코어의 동작. 확장 지점이 기본 구현으로 돌아가서 생기는 변화다. 예: 멤버 한도가 없어짐
- **데이터가 있는 원격 DB 가 걸리면 멈추고 묻는다.** 예: 이미 배포한 `billing` 스키마.
  - 스키마를 지우는 마이그레이션을 너 마음대로 쓰지 않는다. 데이터가 사라진다.
  - 모듈의 마이그레이션 파일을 로컬에서 지우는 것은 괜찮다. 다만 원격에 올라간 뒤라면 원격의 이력과 어긋난다. 그 경우도 묻는다.

### 2. 작업 트리를 깨끗하게 한다

`/scaffold-add` 의 2번과 같다.

### 3. 기계식 반쪽을 돌린다

```bash
node <source>/scripts/module-patch.mjs remove <모듈> --project .
```

| 결과 | 뜻 |
|---|---|
| 지운 파일 | 모듈이 가진 자리 |
| 패치가 붙은 파일 | 표시 줄 · 의존 · 문서 줄을 걷었다 |
| **기준과 다른 채 지운 파일** | 프로젝트에서 모듈의 파일을 고쳐 썼거나 원본이 바뀐 것이다. 프로젝트의 고침이면 코어로 옮겨야 할 것이었는지 `git diff` 로 보고 알린다 |
| **붙지 않은 조각** | 파일 옆에 `.rej` 가 남았다. 4번에서 푼다 |

### 4. 남은 자리를 푼다

- **`.rej` 조각.** 조각이 빼려던 줄(`-`)을 그 파일에서 찾아 걷고, `.rej` 를 지운다.
- **남은 표시 줄.** `scaffold:module <모듈>` 로 온 저장소를 찾는다. 남은 표시가 있으면 걷는다. 블록은 `begin` ~ `end` 를 통째로 걷는다.
- **남은 import.** 모듈의 패키지와 폴더(`owns.json` 의 `packages` · `imports`)를 import 하는 곳이 남았는지 본다.
  - `check:modules` 가 잡는다.
  - 프로젝트가 모듈 밖에서 모듈의 코드를 쓰기 시작했다면, 걷어 내기 전에 사람에게 묻는다.
- **판단이 드는 자리.** `wiring.md` 의 「코어의 동작이 모듈에 기대는 자리」를 하나씩 본다. 기본 구현으로 돌아가도 되는지 판단한다.

### 5. 설치하고 검사한다

```bash
npm install
supabase db reset
```

- `supabase db reset` 은 로컬 데이터를 모두 지우고 컨테이너를 다시 띄운다. 뗀 모듈이 스키마를 가졌을 때(`owns.json` 의 `schemas`)만
  부르고, 부르기 전에 사람에게 말한다.
- `.env.development.local` 처럼 git 이 모르는 파일에 남은 그 모듈의 블록(`scaffold:module <모듈> begin` ~ `end`)은 사람이 치울 일로 보고한다.
- `acceptance.json` 의 `checks` 를 돌린다. 스크립트가 끝에 프로젝트의 스코프로 바꿔 찍은 명령을 쓴다. 이 모듈의 `unit` · `contract` · `e2e` 는 함께 사라졌으니 돌리지 않는다.
- 코어의 검사를 돌린다: `npx turbo typecheck test` · web e2e 전체 · agent e2e.
