# ChatGPT 앱 제출

근거: OpenAI 문서 app-submission-guidelines 의 「Test credentials」와 deploy/submission. 한글파일럿에서 먼저 했다(hwp-pilot#30, SSO-43).

## 리뷰 계정

- 조건: 이메일 + 비밀번호, MFA · 메일이나 문자 코드 · 매직 링크 없음, 기능 전부와 본보기 데이터, 다음 심사 때도 남아 있을 것.
- 구현
  - 전용 `/review-login` 페이지. 평소 로그인은 구글만 그대로 둔다.
  - 서버 액션은 환경변수 `REVIEW_ACCOUNT_EMAILS` 허용 목록만 받는다(글자 그대로 일치, 대소문자 · 공백 무시).
  - 프로덕션에 비밀번호를 가진 다른 사용자가 없는지 본다.
  - 리뷰 테넌트 시드 SQL 은 멱등으로 쓰고 프로덕션에 한 번 돌린다(유료 요금제, 본보기 데이터, 온보딩 답을 미리 채움).
  - 순서 안내: `/review-login` 으로 로그인 → ChatGPT 에서 연결.
- **비밀번호는 만든 스레드 밖으로 옮기지 않는다.** 메모리 · 공유 폴더 · PR · Linear 에 적지 않는다.
- 심사자는 영어로 보므로 영어 화면을 먼저 세운다(hwp-pilot#36).

## 제출 양식에 들어갈 것

- 테스트 케이스: 성공 **5개**와 실패 **3개**를 정확히. 각 줄은 「사용자가 말한 것 → 불릴 도구 → 보여야 할 것」.
  실패 케이스는 거절 · 빈 결과 · 권한 없음처럼 우리가 정한 실패의 모양을 보인다.
- 데모 영상: 실물 ChatGPT 에서 설치 · 연결 · 핵심 흐름.
- Review details: 리뷰 계정과 순서(꾸러미 안이 아니라 양식에 적는다).
- 앱 이름 · 설명(상표 고지 포함) · 10KB 미만 로고 · 처리방침과 약관 주소 · 지원 메일.

## 제출 뒤

- 앱 id 가 확정되면 홈의 「ChatGPT에서 열기」 상수와 딥링크를 맞춘다.
- 오픽뉴런도 같은 순서로 한다(한글파일럿 다음).
