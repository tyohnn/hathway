# 고친 예시

규칙만 읽으면 기준이 흐려진다. 아래는 실제로 고친 글이다. 첫 표는 이 스캐폴드를 세우면서 에이전트가 쓴 글을

### 둘째 판: 검토자(`ux-writing-reviewer`)가 찾은 것

첫 판을 고친 뒤 기계 검사는 조용했다. 아래는 새 맥락의 검토자가 읽고 찾은 것이라 전부 판단의 몫이다.

| 자리 | 전 | 후 | 까닭 |
|---|---|---|---|
| 메타 설명 | 고객과 운영팀이 함께 쓰는 자리 | (지움) | 기능 소개 · 안쪽 조직의 말 |
| 탭 제목 | 허용되지 않은 계정 · Scaffold | 들어갈 수 없는 계정 · Scaffold | 화면 제목은 고쳤는데 탭 제목에 판정의 말이 남았다 |
| 탭 제목의 모양 | 화면마다 「… · 앱 이름」을 손으로 적음 | 루트에 `title.template`, 화면은 앞말만 | 한 앱의 탭이 두 이름으로 갈렸다 |
| 스크린리더 이름 | Toggle Sidebar · breadcrumb | 메뉴 열고 닫기 · 현재 위치 | 보이지 않는 글도 글이다 |
| 블록 기본 제목 | Resolv | (비움) | 다른 제품의 이름이 기본값에 남아 있었다 |
| 로그인 제목 | 계정으로 로그인 | 로그인 | 바로 아래 버튼 「Google 계정으로 로그인」과 겹친다 |
| 진행 중 버튼 | 구글 계정을 확인하고 있어요 | Google 계정을 확인하는 중 | 누르기 전 「Google」이 누른 뒤 「구글」로 바뀐다. 다른 진행 표시(「쓰는 중」)와 모양을 맞춘다 |
| 로컬 칸의 배지 | 로컬 전용 | (지움) | 옆 제목 「로컬 계정으로 로그인」과 같은 말 |
| 입력 오류 | 본문은 4000자까지… | 내용은 4000자까지… | 라벨은 「내용」으로 바꿨는데 오류만 옛 말 |
| 오류의 마침표 | 제목을 적어 주세요 (마침표 없음, 옆 오류는 있음) | 제목을 적어 주세요. | 같은 자리에서 섞였다 |
| 목록의 「열기」 | 열기 × N | 보이는 글은 그대로, aria-label 「{제목} 열기」 | 스크린리더에는 무엇을 여는지 들리지 않는다 |
| 상세의 경로 표시 | 쪽지 › {제목} | (지움) | 위 띠가 「쪽지」를, 바로 아래 h1 이 제목을 말한다 |
| 보관 버튼 | 보관 | 보관하기 | 버튼은 동사. 「보관하는 중」과 짝 |
| 동의 제목 | {앱}을(를) 연결할까요? | {앱} 연결할까요? | 소리 내어 읽으면 「을(를)」에서 걸린다 |
| 동의 설명 | 연결하면 이 앱이 내 쪽지를 읽고 쓸 수 있어요. | (지움) 목록 첫 줄에 「내 쪽지 읽고 쓰기」 | 권한을 목록과 문장이 따로 늘어놓았다 |
| 끝난 동의 | 연결 요청이 끝났어요 | 연결 요청을 찾을 수 없어요 | 「끝났어요」는 잘 끝났다는 뜻으로도 읽힌다 |
| 대화의 오류 | (모든 실패에) 답을 받지 못했어요. 다시 보내 주세요. | 상태마다 까닭(너무 길다 · 다시 로그인 · 종료된 대화), 보낸 글은 입력칸에 되돌림 | 다시 보내도 같은 결과인데 다시 보내라고 했고, 입력칸은 이미 비어 있었다 |
| 종료된 대화 | 끝난 대화예요. 새 대화를 시작해 주세요. | 종료된 대화예요. + 「새 대화 시작」 링크 | 할 일을 말하는데 누를 곳이 없었다. 목록의 「종료」와 이름도 맞춘다 |
| 도구의 답 | 볼 수 있는 쪽지예요. 볼 수 있는 쪽지가 없어요. | 쪽지 N개: … / 볼 수 있는 쪽지가 없어요. | 앞말과 뒷말이 부딪혔다 |
| 도구의 실패 | 쪽지를 읽지 못했어요: {오류 원문} | 쪽지를 읽지 못했어요. (원문은 서버 기록) | 모델이 원문을 사람에게 옮길 수 있다 |
